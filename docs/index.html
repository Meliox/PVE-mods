PVE-mods APT Repository

Official Debian repository for PVE-mods.

Installation

Run as root on the Proxmox VE host. Stable contains published non-prereleases with Debian packages and is recommended for normal installations. APT selects the highest available version by default.

install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://pve-mods-apt.meliox.workers.dev/pve-mods.gpg \
  -o /etc/apt/keyrings/pve-mods.gpg
chmod 0644 /etc/apt/keyrings/pve-mods.gpg

echo "deb [signed-by=/etc/apt/keyrings/pve-mods.gpg] https://pve-mods-apt.meliox.workers.dev stable main" \
  > /etc/apt/sources.list.d/pve-mods.list

apt update
apt install pve-mods

Testing channel

Testing contains published prereleases with Debian packages. After installing the signing key above, replace the stable source with testing to opt in:

echo "deb [signed-by=/etc/apt/keyrings/pve-mods.gpg] https://pve-mods-apt.meliox.workers.dev testing main" \
  > /etc/apt/sources.list.d/pve-mods.list

apt update
apt install pve-mods

A channel is empty until a matching release has been published. Switching back to stable does not automatically downgrade an installed testing version. Both channels have signed metadata, allowing APT to verify the package indexes and downloaded package checksums.

Installing an older version

Only the 100 newest published releases by publication date are retained, counting stable releases and prereleases together.

List versions available in your configured channel, then select an exact version. For example, if 2.1.0 is listed:

apt update
apt-cache madison pve-mods
apt-get install --allow-downgrades pve-mods=2.1.0

Downgrades may be incompatible with your configuration or Proxmox version. A later upgrade will select the highest available version again.

Changelogs

View the changelog for the candidate version, or an exact available version:

apt changelog pve-mods
apt changelog pve-mods=2.1.0

Existing users of trusted=yes should run the installation commands above to install the key and replace the old source entry. The initial key download relies on HTTPS; verify its fingerprint against the maintainer's signing key through an independent trusted source:

gpg --show-keys --with-fingerprint /etc/apt/keyrings/pve-mods.gpg
