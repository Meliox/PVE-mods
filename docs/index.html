PVE-mods APT Repository

Official Debian repository for PVE-mods.

Installation

Run as root on the Proxmox VE host. Stable contains the latest published non-prerelease and is recommended for normal installations.

echo "deb [trusted=yes] https://pve-mods-apt.meliox.workers.dev stable main" \
  > /etc/apt/sources.list.d/pve-mods.list

apt update
apt install pve-mods

Testing channel

Testing contains the latest published prerelease. To opt in, replace the stable source with testing:

echo "deb [trusted=yes] https://pve-mods-apt.meliox.workers.dev testing main" \
  > /etc/apt/sources.list.d/pve-mods.list

apt update
apt install pve-mods

A channel is empty until a matching release has been published. Switching back to stable does not automatically downgrade an installed testing version. Repository metadata is unsigned; trusted=yes disables APT signature checks for this source.
